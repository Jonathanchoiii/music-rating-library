# RecordShelf 版本变更记录

本文件只记录已经进入代码或打包产物的变化。产品规则与验收标准以
[`PRD.md`](../PRD.md) 为准，维护分工见 [`MAINTENANCE.md`](MAINTENANCE.md)。

## 0.1.27 — 2026-08-27

### 添加唱片入口

- 修复加入「漫游」后添加唱片入口反复消失的问题：底部导航保持音乐库、艺人、漫游、搜索和设置五项；桌面与手机统一在音乐库首页右侧显示「＋ 添加唱片」悬浮按钮，不再重复保留桌面页头入口。4174 本机只读预览中的按钮会跳转到 4173 可写添加页，公网只读预览仍不暴露无效写入口；返回顶部和 Toast 会自动向上错开。

### 漫游听歌地图

- 补齐音乐库到艺人管理的身份链路：应用载入、NeoDB 同步及手动添加唱片后，未映射的艺人署名会自动生成稳定、可持久化的 `RELEASE_CREDIT` 身份；合作艺人分别建档且重复署名不会重复创建。新身份保持空 MBID，进入艺人管理既有的增量 MusicBrainz 作品证据核验后，才可用于后续国家资料核验与漫游点亮。
- 「我的音乐版图」标题右侧新增 50% 默认不透明度的刷新图标：仅在用户点击后扫描已有评分且已有稳定身份、但尚无可靠国家资料的艺人；优先使用确认 MusicBrainz ID，否则只接受唯一精确姓名/别名，刷新中显示旋转状态与安全进度，完成后立即更新地图。4174 本机只读页会转交 4173 执行，公网只读预览不暴露写入口。
- 精简大洲分组标题：移除 `AS`、`EU` 等英文代码，并让中文名和英文全名与下方国家卡片左边缘对齐。
- 精简头部统计：「已到访大洲」只显示当前到访数量，不再追加固定的 `/6` 总数。
- 新增一级「漫游」Tab 与 `/roam` 路由，按亚洲、欧洲、北美洲、南美洲、非洲和大洋洲展示真实听歌足迹；默认只看已点亮地区，也可切换到全部地区判断尚未点亮状态。
- 点亮采用保守证据门槛：艺人至少有一张当前整数评分的本地发行，艺人介绍研究为 `READY`，公开资料保留来源，并且 `publicFacts.country` 可唯一映射到标准国家/地区代码。不会根据艺人名、语言、曲风、出生地描述或发行地区猜测国籍。
- 新增 `/roam/:countryCode` 国家二级页，展示该地区的艺人头像、听过唱片数、平均分，以及真实专辑封面、专辑名和用户评分；唱片详情关闭后返回原国家页，艺人入口继续复用现有艺人详情。
- 漫游视觉已收回 RecordShelf 原有的暖白、系统无衬线字体与细分隔线体系，不再使用割裂的黑色头部或楷体/衬线展示字。Figma `1137:5096` 继续作为信息层级参考，桌面与 390 px 移动视口均完成适配。
- 新增按路由懒加载的 Three.js 互动球体，基于真实国家边界与经纬度绘制；点亮国家显示紫色地理标记和可点击标签，球体低速自转、支持鼠标/触控拖动、响应减少动态效果偏好，并在卸载时完整释放 WebGL 资源。
- 漫游地区卡不再用纯文字国家代码作为默认视觉，改为按 ISO 两位代码从 FlagCDN 懒加载 MIT 开源 SVG 国旗；国旗使用统一圆形裁切、请求不发送 referrer，加载失败时自动回退国家代码。
- 统一移除漫游主页面与国家详情页互动球体容器的紫色背景、紫色内框及球体下缘的紫色环境光染色，改为透明暖白底、中性灰边线和暖灰球体阴影；紫色继续仅承担点亮国家和交互状态提示。
- 精简互动球体容器边界：保留一层中性灰外框，移除原先内缩的第二层装饰框，主漫游页与国家详情页保持一致。
- 新增显式本机维护命令 `npm run backfill:roam-countries -- --write`：扫描已有评分且已有稳定身份的艺人，按确认 MusicBrainz ID 或唯一精确名称/别名补齐公开国家资料；同名歧义、无国家或无法映射的结果直接跳过。首次执行与一次失败重试后，实际漫游页更新为 8 个地区、4 个大洲、97 位确认艺人与 352 张听过唱片。
- 香港、澳门改为明确独立地区：分别使用 `HK`、`MO` 的地图标记、地区卡、统计和二级页，中文名称固定为「香港」「澳门」；MusicBrainz 返回的“中国香港特别行政区 / 中国澳门特别行政区”等完整名称也只映射到各自地区，不并入中国。
- 本功能不迁移、不复制也不改写私人资料，只从现有发行、评分、艺人身份和艺人公开资料实时派生。新增漫游逻辑、路由、坐标与互动球体契约测试，并通过全套应用测试和生产构建。

### 艺人探索目录

- 艺人详情「探索模式」从空状态升级为用户主动刷新的真实 Apple Music 目录：按已确认 Artist ID 分页读取 LP、EP、Single 和曲目，缓存成功结果并显示专辑封面、名称、类型、日期与可展开曲目。
- 本地唱片有整数评分时视为已听；优先按确认的 Apple Album ID 匹配，只有艺人范围内唯一的精确标题、兼容类型与日期证据才允许回退。未听曲目灰显，同一录音优先按 ISRC 跨 Single/EP/Album 去重并联动点亮。
- 新增「歌手完成度」：以已听唯一录音数除以目录唯一录音数，展示百分比、歌曲计数、已评分唱片数与本地匹配数。普通打开、NeoDB 同步与启动不联网，刷新失败保留上次成功目录，且外部请求不包含评分、评论或收听日期。
- 修复 4174 只读预览中「开启探索模式 / 拉取作品目录」点击无反馈：现在允许本次预览临时读取公开目录并在内存中展示，但仍不写入共享状态，刷新页面即恢复权威数据。
- 探索目录将同基础标题、同发行日期且同类型的重复发行默认折叠为一个主条目；基础标题会识别并剥离 Remix、Mix、Edit、Version、Remaster、Deluxe、Live 等明确版本限定词，因此同日的 `Streets (Disclosure Remix)` 与 `Streets (Silhouette Remix)` 也会归为一组，但不会仅因日期相同误合并其他单曲或普通章节副标题。优先展示已评分或已匹配的本地版本及其曲目，在副文案中标明另有多少同日版本被折叠；歌手完成度仍按完整目录的唯一录音计算。

### 数据与隐私

- 应用与桌面包版本更新为 0.1.27。首次在可写的 4173 Web 或 Mac 打开新版时，会为音乐库中尚未进入艺人管理的署名增量创建稳定本地身份；不覆盖已有艺人主名、别名、MBID、评分、评论或听歌历史。
- MusicBrainz 与漫游国家核验仍只发送公开艺人身份锚点，不发送评分、评论、听歌日期或收藏状态；国家批量核验只由用户点击漫游刷新或显式本机命令触发。

## 0.1.25 — 2026-08-18

### 修复与调整

- 艺人介绍 Codex 长文不再继承 `~/.codex/config.toml` 里给编程用的模型。ChatGPT 登录当前会拒绝 `gpt-5.2`，以前每次点击都会在 CLI JSONL 里 400，界面却只显示「Codex 长文未完成」。现在使用 `--ignore-user-config` 走 ChatGPT 账号可用的 CLI 默认模型；若 `RECORDSHELF_CODEX_MODEL` 仍不被支持会再试一次默认模型，并把真实原因映射成明确提示。聆听指南本机 Codex 调用同样忽略用户 coding 模型。

## 0.1.22 — 2026-08-18

### 新功能

- 艺人详情的平台主页图标现在由已确认链接实时驱动：保存 Apple Music、Spotify 或 YouTube Music 艺人主页后，对应图标立即高亮并可跳转；未填写的平台保持禁用，链接编辑继续使用独立铅笔入口。
- 艺人索引新增艺人详情抽屉：沿用发行详情 `690px` 窄抽屉与关闭/返回习惯，桌面和移动端统一使用单列竖排；顶部只保留 Apple Music、Spotify、YouTube Music 艺人主页和 Apple 艺人素材四个紧凑工具图标。
- 艺人详情支持用户为当前艺人保存精确平台主页，并按需读取 Apple Music 艺人静图与动态视觉：目录同时请求 `editorialArtwork` 与 `editorialVideo`，静图优先方形身份图再横版 1400/1000 和 600px 兜底，动态视觉优先方形 1:1 再压缩为本机 H.264 MP4（先 1080×1080 / 30fps / crf 18；超 8 MB 先自动截短时长，再降档，直到 ≤8 MB）。体积超限不再失败回退静图，只有完全没有可播放视频时才保留高清艺人图；不触发全库扫描，也不抓取第三方 artwork-finder 页面。旧 WebP 仅在用户点击素材刷新后替换。
- 艺人详情展示本地确认的主显示名、别名、收录数量与平均分；顶部视觉先安全复用该艺人已有发行封面，避免未核验外部图片造成错人。
- “我的收录”支持 `全部 / LP / EP / Single / 未分类` 切换，按发行日期从新到旧排列；专辑可切换为紧凑列表或封面宫格，并按艺人记住选择；从艺人详情打开发行后，关闭发行详情会回到原艺人详情。
- 探索模式开关写入 Web 与 Mac 共用的本地增量；当前阶段不自动联网、不伪造待解锁作品，后续只能由用户手动刷新精确目录。
- 合作关系按 RecordShelf 本地共同署名精确统计，可继续进入对方艺人详情。
- 艺人介绍的手动更新入口已接入本机研究服务：优先使用已确认 MusicBrainz Artist MBID，否则只接受唯一的高置信精确姓名/别名结果；读取并缓存出生或成立日期、地点、国家/地区、艺人类型、流派、团体成员、来源和可用的 Wikipedia 公开简介。Codex 长文仍只走本机已登录 CLI；不可用、未登录、超时或失败时保留公开档案并作为部分成功展示，不自动换 Gemini/OpenAI。同名有歧义时保持空白并提示先绑定 MBID，普通打开与同步不会自动联网。
- 艺人公开简介补充 Wikidata sitelink 降级链：从已核验 MusicBrainz 身份读取 Wikidata 条目，优先中文 Wikipedia、再尝试英文 Wikipedia；任一介绍源不可用时仍保留已经确认的出生、地区、流派与团员等结构化事实。
- 艺人详情支持点击抽屉外左侧遮罩关闭，身份区移除“原始艺人署名”冗余眉题；顶栏去掉通用「艺人详情」标题。已核验艺人照片或动态素材撑满抽屉宽度并裁成 1:1；渐变模糊只占正方形下部底带（固定 36% 高、实心 94%），用更长缓入过渡到暖白，去掉发丝分隔。姓名、统计和平台图标叠在该下部渐变上，「我的收录」从 1:1 框下沿开始。头图渐变比例已固化进 CSS，不再提供「头图渐变」调节器。关闭按钮叠在照片上时反白，叠在纯色表面时恢复深色。封面拼贴回退仍内缩。资料更新状态、失败信息和结果会在当前页面即时显示并写入 Web/Mac 共用本地增量。
- 详情封面刷新按钮仅在桌面悬停或聚焦时以 30% 不透明度出现，相对原内缩再向右、向下各移 8px；动态封面上同样可用。本地 `/private-covers/` 缺失或无法解码时，网格和详情先显示已保存的远程 `coverRemoteUrl`，Mac 读封面时额外回退到本机 `.private/covers`。

### 修复与调整

- 艺人静图现在优先使用 Apple 方形身份图（`artwork` / `staticDetailSquare`），没有方形时才用横版 `subscriptionHero`。1:1 Hero 因此会显示与 YouTube Music 头像同一张官方照片，而不是把 4:1 横幅中心裁切；仍只读已确认 Apple Music 艺人目录，不抓 YouTube 头像或第三方图片。已缓存的横版图需用户再次点击素材刷新才会换成身份图。
