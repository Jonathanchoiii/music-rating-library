# RecordShelf 版本变更记录

本文件只记录已经进入代码或打包产物的变化。产品规则与验收标准以
[`PRD.md`](../PRD.md) 为准，维护分工见 [`MAINTENANCE.md`](MAINTENANCE.md)。

## 0.1.21 — 2026-08-16

### 修复与调整

- 发行详情顶栏去掉通用「发行详情」标题，只保留右侧关闭；对话框仍用发行标题作为可访问名称。
- 详情模块标题（专辑介绍、曲目列表、收听时间、聆听指南、平台评分）统一为 20px。
- 发行类型与平台/动态封面图标仍在同一工具行；只有窄宽度折行时，第二行左侧补与「发行类型」同款的「收听链接」，单行不出现该标题。
- 「专辑介绍」空状态说明改为「可手动添加或配置令牌自动拉取」；不改写 Apple 官方原文，也不加「我写的」标识。
- 为 macOS 客户端增加单实例锁：重复双击当前版本只激活已有窗口，不再启动第二个服务并误报 `4173` 被占用；真正由历史客户端占用端口时仍保留明确退出提示，避免新版加载旧 UI。
- 发行详情顶部新增克制的封面取色氛围：封面在本机缩小为 20 × 18、共 360 个等面积采样格，只以占比最大的单一 HSB 色簇生成轻渐变，不再混入第二颜色。为避免深色封面形成压迫的深底白字，主色按 `B新 = B旧 + (100 - B旧) × 0.7` 提高明度，保留原色相与饱和度，并固定使用浅色背景与黑字；渐变层整体降为 50% 不透明度，范围收敛至详情顶部约 195px，并在进入封面主体前淡回暖白。修复 NeoDB 等跨域远程封面无法取色、导致渐变透明度始终为 0 的问题：本机服务现在仅对固定可信 HTTPS 图片域名提供受 MIME 与 15 MB 上限保护的临时同源字节回退，不保存或上传封面、不写入唱片元数据，失败时仍静默保持原背景。
- 取消窄屏唱片架的纵向 Cover Flow 分支；桌面、窄窗口与手机现在统一使用五张一层的横向实体唱片架，并按容器同步收紧封面、间距、层高、编号和 hover 位移。
- 移除「专辑介绍」底部重复的「在 Apple Music 中打开」链接；Apple Music 跳转统一保留在详情头部的平台图标区。
- 恢复发行详情右侧 NeoDB、Apple Music、Spotify 图标的桌面右键链接编辑：组件自身处理右键事件，打开添加、修改或清除链接的站内菜单。
- 保持移动端长按链接图标进入同一编辑流程；平台链接继续写入 Web 4173 与 Mac 共用的用户增量，不只停留在当前页面。
- 收紧事件边界：不再用捕获阶段提前拦截目标组件，也不在 Electron 主进程全局禁用所有原生 `context-menu` 事件，避免链接编辑失效并保留其他界面的正常右键能力。
- 修复旧客户端仍占用 `4173` 时，新客户端静默复用旧版页面的问题：现在会明确提示先退出旧进程，不再让废纸篓或历史安装包伪装成当前版本。已在当前构建上实测右键后出现「修改链接 / 清除链接」。
- Mac Dock、应用窗口与 DMG 统一使用用户提供的 `record` 素材。移除启动后的 `app.dock.setIcon()` PNG 覆盖，改由 `.app` bundle 图标统一承接关闭与运行状态，修复未打开时圆角正常、打开后却变成方形的问题。
- 应用与桌面包版本更新为 0.1.21。
- 修复「更新专辑封面图」把仍可访问的旧 NeoDB 远程地址直接缓存后计为成功的问题：现在会先按已确认的 Apple Music / Spotify 精确链接重新解析；两者都返回时记为精确平台共识，覆盖过期 NeoDB OG。空白或客户端加载失败的旧地址不会靠 `coverRemoteUrl` 回退成成功。本地 `/private-covers/` 被覆盖后用 `coverMatchedAt` 刷新图片请求。
- 发行详情英雄封面在桌面悬停或键盘聚焦时，右下角出现 30% 不透明度的刷新按钮；点击只对当前这张发行 `force` 重解析精确链接封面，即使本地 `/private-covers/` 已存在也不空转。手机保持 44 × 44 热区。设置页批量「更新专辑封面图」仍先处理空缺、失败和远程封面。网格与唱片架不显示该控件，也不恢复独立平台链接行。

### 数据与隐私

- 本版本不迁移、不重置也不合并私人音乐数据；继续使用
  `~/Library/Application Support/RecordShelf/shared-local-state.json` 作为 Web 与 Mac 的共享用户增量。
- 平台链接修改仍通过现有共享增量写入；没有新增凭证、私人目录或远端传输字段。

### 验证

- 应用测试：230 项通过。
- Sites worker 测试：7 项通过。
- Web 构建、桌面 Web 构建和公开构建隐私检查通过。
- Electron 主进程、本机服务和后台 worker 语法检查通过；Git 冲突标记、未合并索引和空白错误检查通过。
- 本地 Apple Silicon DMG：`app/desktop-release/RecordShelf-0.1.21-arm64.dmg`。

### 已知限制

- 本地 DMG 使用 ad-hoc 签名，未使用 Apple Developer ID 公证，不适合作为公共安装包分发。
- 现有前端仍有较大的代码分块构建警告；不影响本次功能，但后续应单独做按路由/功能拆包，而不是与交互修复混改。

## 0.1.20 — 2026-08-15

- 用户元数据改动即时写入共享状态，降低 Web 与 Mac 间重新打开后丢失修改的风险。
- 收敛曲目列表和搜索界面，并补充 Mac 关机后的手机只读快照预览能力。
- 手机预览只读、私人快照不进入 Git/DMG；具体流程见 [`PHONE_PREVIEW.md`](PHONE_PREVIEW.md)。
