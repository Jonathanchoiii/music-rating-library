# RecordShelf 漫游规格

「漫游」把已经听过、且国家/地区能够可靠确认的艺人整理成个人世界听歌地图。它是回顾与探索界面，不是新的音乐资料库，也不保存第二份统计结果。

## 点亮资格

一个艺人只有同时满足以下条件才进入漫游：

1. 该艺人至少有一张本地发行存在当前整数评分；沿用 RecordShelf 的既有语义，已评分即视为已经听过。
2. 艺人公开资料的 `introductionStatus` 为 `READY`。
3. 自动确认的国家至少保留一个可核验 `source`；用户在艺人介绍中从标准国家/地区目录明确保存的 `USER_CONFIRMED` 视为本机人工证据，不伪造网页来源。
4. `publicFacts.country` 能按完整名称或显式别名唯一映射到标准两位地区代码。
5. `roamCountryAudit` 为 `CONFIRMED`，且国家证据等级是 `WIKIDATA_COUNTRY`、`USER_CONFIRMED_APPLE` 或 `USER_CONFIRMED`。MusicBrainz MBID 和本地 Release Group 只确认艺人身份；自动国家证据另行读取 Wikidata 的个人国籍 `P27` 或团体起源国家 `P495`。MusicBrainz `Area / country`、多值冲突或无法取得唯一 ISO 两位代码时，艺人详情的地区与来源地保持空白，漫游不点亮。

不得从艺人名、歌曲语言、曲风、出生地/成长地自由文本、厂牌、专辑发行地区、IP 或其他弱信号猜测。未研究、研究未完成、无来源、未评分或无法精确映射的艺人均不点亮；这些排除不改变原始艺人资料。

香港与澳门始终使用独立的 `HK`、`MO` 地区代码、卡片、统计和国家页，界面名称固定为「香港」「澳门」，不并入 `CN`。公开来源返回「中国香港特别行政区」「中华人民共和国香港特别行政区」「中国澳门特别行政区」等完整名称时，只归一到各自的 `HK` 或 `MO`。

## 信息架构

- `/roam`：一级漫游页，页面主标题为「音乐漫游」。展示已点亮地区数、已到访大洲数、确认艺人数和听过唱片数；四项统计在竖屏与横屏都固定为两列两行，已到访大洲只显示当前数量，不追加 `/6` 总数。
- 「我的音乐版图」标题右侧提供一个默认 50% 不透明度的刷新图标。点击后只核验已有评分、已有稳定身份，且尚未完成当前身份版本国家核验的艺人；每次最多处理前 100 位，完成后立即保存并提示仍待处理数量，下一次点击继续下一批。刷新中图标旋转，并通过现有 Toast 报告安全进度与结果。已经核验过的艺人不会因为再次点击而重复联网。
- 默认「已点亮」：只展示有符合资格艺人的国家/地区，并按六大洲分组。大洲标题不显示英文代码，中文名和英文全名与下方国家卡片左边缘对齐。
- 「全部地区」：展示标准目录内所有地区；未点亮项以低强调锁定状态呈现，不可进入伪造内容页。
- 地球上的浮动标签使用“小国旗 + 中文地区名 + 艺人数”；不在中文名前显示 `US`、`JP`、`KR` 等英文代码。旗帜沿用地区卡的同一开源资源并禁用 referrer，加载失败时才回退两位代码。
- `/roam/:countryCode`：国家二级页。展示国家/地区名、大洲、首次点亮日期、艺人数、听过唱片数与平均评分。
- 国家页按艺人分组，展示艺人头像、艺人平均分，以及每张已评分发行的真实封面、专辑名和评分。点击唱片复用现有发行详情，关闭后回到原国家页；点击艺人时在当前 `/roam/:countryCode` 路由上叠加现有艺人详情，漫游 Tab 继续高亮。关闭、Escape 或点击抽屉外遮罩后移除艺人参数，原国家页、筛选状态与滚动位置保持不变。若从该艺人详情继续打开唱片，关闭顺序固定为唱片 → 艺人 → 国家页。

## 数据与隐私

- 漫游模型在客户端从 `releases`、`artistIdentityState` 和 `artistProfileState` 实时计算，不新增 localStorage 键、远端同步或国家统计缓存。为避免重复联网，既有艺人档案可保存一个轻量 `roamCountryAudit`：只含终态、核验时间和由主名、别名、MusicBrainz ID 生成的身份指纹，不复制国家统计。
- 评分、评论、听歌日期和艺人映射不会发送给第三方。国家字段来自用户主动触发的单艺人公开研究、漫游页刷新图标、艺人介绍事实区的手动地区选择，或显式执行的本机 `npm run backfill:roam-countries -- --write` 维护扫描。地区编辑器从标准目录搜索并单选，保存只更新当前稳定艺人档案的 `publicFacts.country` 与 `CONFIRMED + USER_CONFIRMED`；既有介绍、其他公开事实、来源、封面、链接、映射、评分、评论和听歌记录不得被空补丁或地区修改清除。两种批量扫描都先独立确认艺人身份：优先使用已绑定的 MusicBrainz ID；没有确认 ID 时，唯一精确名称/别名结果还必须包含至少一个与本地唱片精确同名的 Release Group。身份确认后，国家必须再由 Wikidata 的个人 `country of citizenship (P27)` 或团体 `country of origin (P495)` 给出唯一可解析 ISO 两位代码；MusicBrainz `Area / country` 只视为关联地区，不得写作国籍。可靠自动国家写为 `CONFIRMED + WIKIDATA_COUNTRY`；用户按精确 Apple Artist ID 确认的更正写为 `CONFIRMED + USER_CONFIRMED_APPLE`；界面手动选择写为 `CONFIRMED + USER_CONFIRMED`；来源无唯一国家写为 `NO_COUNTRY`；名称或作品证据无法唯一确认写为 `AMBIGUOUS`。旧 `CONFIRMED_MBID / EXACT_RELEASE_GROUP` 成功结果不再点亮并重新进入手动核验队列，但不自动联网、不删除档案。两种用户确认结果都高于批量任务，在途旧响应、后续自动研究和身份归并也不得覆盖；用户仍可再次手动更换。三种终态在身份指纹未变时直接跳过；新增身份，或尚未成功点亮且身份指纹变化时重新核验。网络中断或服务不可用等临时失败不写终态，下一次点击仍可重试。命令行只有显式增加 `--force` 才重查全部符合资格的艺人。扫描不会在启动、同步或普通打开漫游时自动运行；4174 本机只读页只可跳转到 4173 发起，公网只读预览不提供入口。
- 只读远程预览可展示已经存在于快照中的漫游结果，但不能触发研究或修改资料。
- 艺人评分、资料或映射改变后，漫游结果随现有状态更新；不保留可能过时的手工点亮开关。

## 视觉与响应式

- Figma 节点 `1137:5096` 提供听歌护照的信息层级、世界地图意象、地区状态、大洲分组和国家页艺人/专辑层级；视觉表面继续使用 RecordShelf 既有暖白背景、系统无衬线字体、近黑文字、紫色状态、琥珀评分、桌面侧栏和移动底部导航，不使用割裂的黑色头部、楷体或其他衬线展示字体。
- 世界地图由懒加载的 Three.js 球体承载，基于标准国家边界数据；符合资格的国家在真实经纬度显示紫色标记和可点击标签，未点亮国家不显示伪造标记。球体默认低速自转，鼠标与触控可拖动旋转；禁用缩放和平移，并尊重系统“减少动态效果”。
- 球体随容器尺寸和像素倍率自适应；外层始终保持 `1:1` 比例且不依赖固定最小高度，拖动桌面窗口或改变移动视口时，画布与地球按可用宽度同步等比例缩放。国家标签只在对应坐标位于正面及安全画布范围时出现。卸载时必须停止 animation loop、断开尺寸监听并释放 OrbitControls、几何体、材质与 renderer。
- 桌面主视觉采用暖白双列布局，移动端改为单列并保留完整互动球体。主页面和国家页的球体容器都使用透明暖白底与单层中性灰外框，不再叠加内缩的第二层装饰框；球体环境光使用中性暖灰，不使用紫色背景底、紫色内框或紫色阴影染色。紫色仅用于点亮标记、标签代码与操作状态。国家卡桌面最多三列、移动单列；专辑封面桌面六列、移动两列。
- 主页面的眉题、标题「音乐漫游」和说明文字与音乐库、艺人等其他一级 Tab 共用相同的内容左缘、顶部起点与标题字号；漫游页面不额外居中内缩。
- 国家卡使用 `https://flagcdn.io/flags/4x3/{iso2}.svg` 的 MIT 开源国旗素材，按 ISO 两位代码懒加载、圆形裁切并关闭 referrer；外部素材失败时回退到同尺寸两位代码圆标，卡片文案、状态和导航保持可用。
- 所有可操作项保持语义链接或按钮、可见键盘焦点和实用触控尺寸。页面不得产生横向溢出。

## 验收标准

1. Given 一个有评分发行、`READY` 公开资料、至少一个来源且国家可映射的艺人，When 打开漫游，Then 对应国家与大洲被点亮且统计包含该艺人和发行。
2. Given 任一资格缺失，When 打开漫游，Then 该艺人不参与点亮或统计，且不会用其他字段推断国家。
3. Given 一个已点亮国家，When 进入国家页，Then 可以看到该国符合资格的艺人、真实专辑封面、专辑名和当前评分。
4. Given 从国家页打开唱片详情，When 关闭详情，Then 返回同一国家页并回到页面顶部。
5. Given 390 px 移动视口和桌面视口，When 浏览漫游主页面和国家页，Then 不出现横向溢出、遮挡或不可操作控件，球体能自转、拖动并在正确地理位置展示已点亮国家。
6. Given 某艺人已在当前身份指纹下得到 `CONFIRMED`、`NO_COUNTRY` 或 `AMBIGUOUS` 结果，When 用户再次点击核验，Then 该艺人不进入请求队列；新增艺人或尚未点亮且身份指纹变化的艺人进入队列，临时失败艺人仍可重试。
7. Given 用户从某国家页的艺人卡打开艺人详情，When 关闭详情、按 Escape 或点击遮罩，Then 返回同一国家页、漫游 Tab 仍选中且页面停留在打开前的锚点；从该艺人再进入唱片时，关闭唱片先恢复艺人详情。
8. Given 用户拖动桌面窗口改变宽度或使用不同移动视口，When 漫游主页面重新排版，Then 球体容器、画布和地球保持 `1:1` 并等比例缩放，页面头部与其他一级 Tab 保持同一对齐基线。
9. Given 本地艺人名与 MusicBrainz 中另一位艺人同名但本地唱片标题不属于该实体，When 执行漫游国家核验，Then 结果记为同名歧义且不写入对方的国家、出生日期、来源或 MBID；只有名称和至少一张本地唱片的 Release Group 标题同时精确一致时才继续。
10. Given 升级前存在名称单独命中且身份 MBID 仍为空的历史国家结果，When 新版构建漫游或艺人详情，Then 该艺人不再点亮，地区与来源地不展示，并回到手动证据核验队列；旧字段仅在本地保留以避免误删。用户用精确 Apple ID 更正后，即使旧核验请求稍后返回，也不能覆盖该用户确认结果。
11. Given 核验返回了一个国家但没有一致的 MBID 与对应 MusicBrainz Artist 来源，When 保存核验结果，Then 只记录 `AMBIGUOUS`，不写入返回的国家、来源、出生日期或 MBID。
12. Given 艺人介绍中的地区错误或为空，When 用户点击地区旁的编辑入口、从完整目录单选并保存，Then 只更新该艺人的地区与 `USER_CONFIRMED` 核验标记，漫游立即移动到对应地区；既有介绍、事实、来源、素材、链接及用户音乐数据原样保留，后续或在途的自动核验不能覆盖手动值。
